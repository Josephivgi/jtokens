API list prices used for cost

Cost is what the same tokens would cost on the pay-as-you-go API at list price. If you use a Claude or ChatGPT subscription you are not billed this amount. Claude: cache writes are 1.25x input (5 minute) or 2x input (1 hour); Claude Haiku 5.5 uses the higher row when a prompt is over 100,000 tokens; fast mode uses the fast price with the same cache multipliers. OpenAI: cached input uses the cached rate; prompts over 272,000 tokens use the long-context row. Codex priority or fast tiers are not detected and are priced at Standard. Models with no public price (for example codex-auto-review) are counted in tokens but not in cost.
